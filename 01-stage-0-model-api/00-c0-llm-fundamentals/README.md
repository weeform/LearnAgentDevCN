# C0 · 大模型工作原理速成（前置课）
**面向**：有编程基础、但没学过大模型原理的人。你是 Agent 开发者，不是算法工程师  
**时长**：约 50-60 分钟（5 篇，每篇 10-15 分钟）  
**定位**：给 C1 和 C2 补上缺失的地基。这是阶段 0 里唯一一门"往底层走"的课

## 为什么补这门课

C1 讲参数时，会直接说"模型输出一个词表大小的向量 = logits"；C2 讲 KV Cache 时，会直接说"每个 token 投影出 Q / K / V"。如果你不知道模型内部长什么样，这两句话是接不住的。

这门课的目的不是让你会写模型，而是让你**读得懂 C1 和 C2，并且能判断一个说法对不对**。它只讲原理，不讲实现细节：不推公式、不写代码、不提反向传播。

**不需要你预先知道**：任何机器学习知识。  
**默认你已知道**：数组、哈希查表、矩阵乘法、函数调用、缓存（通用编程概念都不解释）。

## 这门课回答四件事

1. 大模型到底在干什么？—— 它是一个"预测下一个 token"的函数，仅此而已。
2. token 是什么？为什么模型只认整数和向量，不认字符串？
3. Transformer 是什么？一层网络在里面做了什么？
4. 注意力（Attention）和 Q / K / V 是什么？—— 这是全课最难、也最关键的一节。

## 阅读建议

- **只想读 C1**：读 C0-1 和 C0-2 就够了，知道 token 和 logits 是什么即可。
- **要读 C2**：必须读完 C0-4 再进 C2-2。少了这一步，Q / K / V 就是三个黑箱符号。
- **有环境**：读完 C0-5 后，找个能看 token 概率的 playground，输入一句话，观察"下一个 token 的概率分布"——这比读十遍都直观。
