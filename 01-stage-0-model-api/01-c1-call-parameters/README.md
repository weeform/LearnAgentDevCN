# C1 · 大模型调用参数与原理
**面向**：准备动手写 Agent，但还没系统梳理过 LLM API 参数的人  
**时长**：约 45-60 分钟（5 篇，每篇 8-15 分钟）  
**主轴**：OpenAI 兼容协议（Chat Completions），关键处对比 Anthropic Claude、DeepSeek、通义等

## 学完你能做到

1. 看到任何一家模型的 API 文档，能快速判断「哪些参数是我需要的、哪些可以忽略」。
2. 解释 temperature / top_p 到底改变了哪一步计算，而不是背「越大越随机」。
3. 知道 Agent 场景下每个参数的推荐取值，以及为什么。
4. 能读懂一次带工具调用的请求和响应，知道 Agent 循环该在哪些字段上分支。

## 文档清单

| 编号 | 文档 | 时长 | 解决什么问题 |
|---|---|---|---|
| C1-1 | 课程导览与参数全景图 | 8 min | 一次调用到底发生了什么；参数分几类 |

| C1-3 | 输入、长度与停止 | 12 min | 上下文怎么传；什么时候停；靠什么分支 |
| C1-4 | Agent 核心参数：tools / tool_choice / response_format | 15 min | 结构化输出与工具调用的原理 |
| C1-5 | 速查表与自测题 | 10 min | 固化记忆 + 检验 |

## 阅读建议

- 第一次读：按顺序，不要跳。
- 复习：只看 C1-5。
- 有代码环境：读到 C1-4 时，拿任意一家 API 真实发一次带 tools 的请求对照看。
