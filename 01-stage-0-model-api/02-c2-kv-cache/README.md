# C2 · KV Cache 机制与 Agent 上下文复用
**面向**：读完 C1、想真正搞懂「模型为什么越聊越贵」「长上下文为什么烧显存」「各家缓存折扣到底省的是什么」的人  
**时长**：约 50-70 分钟（5 篇，每篇 10-15 分钟）  
**定位**：连接「模型内部原理」与「Agent 成本 / 上下文工程」的桥梁课

## 这门课回答三件事

1. KV Cache 到底是什么，为什么它能存在（原理 + 模型内部处理流程）。
2. 一个 token 从输入到输出，模型内部到底经历了哪两个阶段，显存和速度各花在哪。
3. Agent 开发者如何把「KV Cache」这个底层机制，落地成「省 50%-90% 成本、降 80% 首 token 延迟」的工程手段。

## 对应 00 总纲的位置

本课程是 00 总纲中两个点的展开与深化：

- **阶段 1.4**（上下文管理：KV Cache 复用）
- **阶段 5.3**（成本：token 预算、缓存、模型分级）

建议在进入阶段 1 之前读，或读到 1.4 / 5.3 时回来精读。
