# C5-3 · 限流、并发、超时与降级
> 阅读约 12 分钟。目标：从"能跑通"升级到"能扛住"。

## 1. 三层限制，别只盯着 QPS

厂商的限制通常是**三层同时生效**：

| 层 | 单位 | 特点 |
|---|---|---|
| **RPM** | 请求数 / 分钟 | 限制小请求 |
| **TPM** | token 数 / 分钟 | **Agent 最容易撞的**——因为每次请求都带全量历史 |
| **并发数** | 同时在途请求数 | 限制突发 |

Agent 的典型翻车方式：请求数不多（RPM 很宽裕），但每个请求 50K token，几个并发就把 TPM 打满了。

**所以监控要以 TPM 为主，RPM 为辅。**

## 2. 客户端要做自己的闸

不能把限流完全交给服务端——429 已经意味着你的用户体验受损。客户端需要：

### ① 并发闸门

```python
sem = asyncio.Semaphore(8)      # 同时在途请求数
async with sem:
    return await call_api(...)
```

并发数设定参考：`并发 ≈ TPM额度 / 单次平均token`。比如 TPM 100 万、单次 20K，理论并发 50，取一半留余量。

### ② 令牌桶（更平滑）

比信号量更平滑的做法：用一个按 token 计数的桶，请求前先"取"预估 token 数，桶空了就等。这样能**直接对齐 TPM 额度**，而不是靠猜并发数。

### ③ 预算器（token budget）

在任务级别设预算：`这个任务最多花 200K token / 最多 20 步 / 最多 60 秒`。超了就停止并降级。这是**成本控制与防跑飞的统一手段**（呼应 C3-3 的平方增长）。

### ④ 优先级队列

- 用户交互式请求：高优先级；
- 后台批处理、评测：低优先级，且主动限速；
- 突发时**先牺牲后台任务**，保住交互体验。

## 3. 超时怎么设

一个常见的错误：只设一个"总超时 60 秒"。结果是用户盯着空白等 60 秒才报错。

正确的分层：

| 超时 | 建议 | 作用 |
|---|---|---|
| 连接超时 | 5～10 秒 | 网络不通，快速失败 |
| **首 token 超时（TTFT）** | 10～20 秒 | 流式场景的关键指标，超时说明"卡住了" |
| 整体超时 | 按任务定（60 秒～数分钟） | 兜底 |

有了 TTFT 超时，你能做到"10 秒内要么开始出字、要么报错/降级"，体验完全不同。

## 4. 降级链：主 → 备 → 兜底

设计原则：**任何一层失败都要有下一层接住**。

```
① 主模型（如 GPT-5.5 / Opus 4.8）
   ↓ 连续失败 / 超时 / 被限流
② 备用模型（同厂商小型号 或 另一家厂商）
   ↓ 仍不可用
③ 缓存答案 / 规则引擎 / 上一版结果
   ↓ 无可用
④ 友好失败：明确告诉用户"暂时不可用，已保存进度，请稍后重试"
```

几个实施要点：

- **跨厂商降级**需要在你的调用层做一层**统一抽象**（消息格式、工具格式、token 计数都不同），这是值得的投资；
- **降级要降级能力而不是正确性**：小模型做不了复杂推理，但可以完成摘要、分类、抽取；
- **降级必须可观测**：记录"本次走了降级"，否则你永远不知道服务实际质量在下滑；
- **熔断**：连续 N 次失败后，短时间内直接走备用，不再浪费时间重试主模型（阈值触发 + 半开恢复）。

## 5. Batch API：一半价格的离线通道

各大厂都提供批处理接口，特点：

| 维度 | 说明 |
|---|---|
| 价格 | 通常**约 50% 折扣** |
| 时效 | 异步，通常 24 小时内完成（实际常更快） |
| 适合 | 离线评测、批量标注、数据回填、夜间任务 |
| 不适合 | 任何"用户在等"的场景 |

对 Agent 开发者最实用的场景：**跑评测集**。你有 200 条测试用例，用 Batch API 跑一遍，半价且不用管限流——这正是阶段 5 要做的事。

## 6. 预算告警与熔断

生产环境必备三件事：

1. **配额水位告警**：TPM 用到 80% 时告警，别等 429；
2. **成本告警**：日/周成本超过阈值就通知（Agent 跑飞一次可能烧掉一周预算）；
3. **单任务熔断**：单任务步数、token、耗时任一超预算就中止并保留现场（对应阶段 2 的最大步数与死循环检测）。

## 7. 小结

- 监控**TPM 为主**，Agent 是 token 密集而非请求密集。
- 客户端要有**并发闸门 / 令牌桶 / 任务预算**三件套。
- 超时分三层，**TTFT 决定体验**。
- 降级链：主模型 → 备模型 → 缓存/规则 → 友好失败；配熔断与告警。
- Batch API 用于离线，**约半价**。
