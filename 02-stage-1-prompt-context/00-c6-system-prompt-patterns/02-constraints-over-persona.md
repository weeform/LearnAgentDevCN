# C6-2 · 约束 > 角色：为什么「你是资深分析师」没用
> 阅读约 10 分钟。目标：破除「角色扮演」迷信，把力气花在真正有效的约束上。

## 1. 一个广泛流传的误解

很多 prompt 教程教你第一句写：

> 「你是一位拥有 20 年经验的资深数据分析师。」

它的隐含假设是：**给模型贴个身份标签，它就会「表现得更像」那个身份**。

实测结论是：**这类身份描述对输出质量的影响微乎其微，有时甚至略降**（模型可能因为「资深」而倾向于长篇大论、堆砌术语）。真正拉高或拉低质量的，是具体的**约束**和**判断标准**。

## 2. 为什么角色牌不好使

模型没有「自我」可以切换，它只是在**预测下一个 token**（见 C0-1）。「你是一个专家」这条指令，能影响的只是它接下来生成的**语言风格**——比如用词更书面、语气更权威——而**不是**它背后知识和推理的「专业程度」。

换句话说：

- 角色牌改的是**外壳**（语气、口吻）；
- 约束改的是**行为**（该做什么、不该做什么、如何取舍）。

你要的是行为改变，不是语气改变。所以该把 token 花在约束上。

### 2.1 一个具体的「越资深越差」案例

同一份客服对话，做「工单字段抽取」，只换 system prompt 第一句。下表是**示意值**（用来呈现趋势，不是某项实测报告），你自己跑出来的绝对值会不同：

| 版本 | 首句 | 字段正确率 | 平均输出长度 |
|---|---|---|---|
| A | （无角色句） | 88% | 210 字 |
| B | 你是一位拥有 20 年经验的客服质检专家 | 85% | 390 字 |
| C | 你是一位资深工单处理专家，请严谨专业地完成任务 | 82% | 460 字 |

三个版本用的是同一个模型、同一批 50 条输入。角色句越"重"，准确率反而越低，输出越啰嗦。

原因不玄学：**"专家"这个词在训练语料里高度关联"分析""建议""从多个角度看"这类行为**，于是模型开始补充对话里没有的信息——而这正是抽取任务最忌讳的。角色牌把任务从「抄字段」推向了「做点评」。

这个现象有个通用名字：**角色牌会引入与任务目标不一致的先验**。任务越"机械"（抽取、分类、转换），这种干扰越明显。

## 3. 什么才是有效的「角色设定」

角色设定不是完全没用，但有效用法是**把身份翻译成可执行的行为约束**。

| 无效写法 | 有效改写 |
|---|---|
| 你是资深律师 | 只引用现行法条，不确定的适用情形要说明争议点 |
| 你是英语母语者 | 输出使用地道的英语表达，避免中式英语，专有名词保持原文 |
| 你是产品经理 | 先复述用户需求，再分「必须 / 可选」两档给出方案 |

看出来了吗：有效版本把「资深」「母语」「产品经理」这些**抽象身份**，翻译成了**具体可验证的行为标准**。模型不需要「理解」身份，只需要照约束执行。

### 3.1 翻译的三步动作

拿到一个身份词，不要直接写进 prompt，先做三步：

1. **问：这个身份的人「会做什么、不会做什么」？** 律师会引用法条、不会替客户下判决；客服会先确认订单号、不会主动给赔偿承诺。
2. **把「会做」写成正向约束，「不会做」写成反向约束。** 这两条才是有信息量的部分。
3. **删掉身份词本身。** 如果前两步写出的约束已经足够，身份词就是冗余的。

做完这三步，通常能得到 2–4 条约束，而原来只有一句「你是资深 XX」。token 花得更值，行为也更可预测。

## 4. 例外：角色牌什么时候真的有用

有少数场景，身份标签能带来可观察的差异：

1. **风格 / 口吻要求明确**时（「用小学生能懂的话解释」）——这本质上是「约束」，只是借了角色之名。
2. **领域术语一致性**（「按金融行业惯例叫法」）——避免模型在不同叫法间漂移。
3. **安全 / 合规对齐**（「你是客服，必须遵守以下红线」）——但这同样是把身份转成了规则。
4. **需要模型「配合语气」的对话场景**——客服机器人、陪伴类应用。此时语气本身就是产品需求，角色牌是达成它的最短路径。

注意前三点里，「角色」都只是「约束」的便捷封装，核心仍然是行为标准。第四点是真例外：**当「像不像那个人」本身就是验收标准时，角色牌才有独立价值**。而这类场景恰恰不需要你论证「专业性提升」。

## 5. 一个可复用的判断句

写 prompt 时，每当你准备写「你是 XX」，先问一句：

> 我把「XX」翻译成一条**可验证的行为约束**了吗？

- 翻译得出来 → 直接写约束，删掉身份牌。
- 翻译不出来 → 说明「XX」本身就没给模型任何信息，留着只是浪费 token。

如果还想更硬一点，就做一次 5 分钟的对照实验：同一批 10 条输入，跑「有角色句」和「无角色句」两版，逐条比对关键字段。**这个实验的成本比争论低得多，结论也比任何教程可靠**——因为它在你的数据、你的模型上成立。

## 6. 小结

- 「你是 XX」改的是语气，不是能力；模型只在预测 token。
- 角色牌会引入与任务目标不一致的先验：任务越机械，干扰越明显。
- 把身份翻译成**具体、可验证的行为约束**，才是有效的角色用法。
- 真例外只有一种：语气本身就是验收标准时。
- 判断句：翻译得出约束就写约束，翻译不出就删。
