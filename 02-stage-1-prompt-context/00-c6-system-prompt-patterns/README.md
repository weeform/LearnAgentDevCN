# C6 · System Prompt 工程与提示词模式
**面向**：已经会调 API，但 prompt 还停留在「想到哪写到哪」的人
**时长**：约 45–60 分钟（5 篇，每篇 8–15 分钟）
**主轴**：把「写 prompt」从玄学变成可复用的工程动作

## 学完你能做到

1. 用五段式模板（角色 / 目标 / 约束 / 输出格式 / 示例）写出结构化的 system prompt。
2. 说清为什么「约束」比「角色扮演」有用得多，并能解释其反例。
3. 判断少样本、思维链、自一致性各自该不该用、要付多少 token。
4. 知道 CoT 在什么情况下反而更差、更贵，避免盲目套用。
