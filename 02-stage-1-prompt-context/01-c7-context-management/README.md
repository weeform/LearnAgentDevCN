# C7 · 上下文管理与压缩
**面向**：开始跑多轮对话 / Agent，发现上下文越涨越大、越来越贵的人
**时长**：约 40–50 分钟（4 篇，每篇 10–15 分钟）
**主轴**：上下文是有限资源，管理它 = 做有依据的取舍

## 学完你能做到

1. 估算一次多轮对话的上下文预算，知道钱花在哪、为什么增长。
2. 说清裁剪、摘要、压缩各自的代价，以及它们和 KV Cache 命中的关系。
3. 设计一套有明确规则的上下文裁剪策略，而不是「砍掉最老的几条」。
4. 掌握上下文装配的基本思路：按需加载、稳定前缀、工具结果落盘。

## 阅读建议

- 第一次读：按顺序。C7-2 依赖 C2（KV Cache），若跳过 C2 建议先补 C2-5。
- 复习：只看 C7-4 的策略模板。
- 有环境：拿一段真实的工具返回，试试「超 N token 就摘要」的策略。
