# C8 · 提示词安全与注入防御
**面向**：开始把模型接进真实数据、真实工具的人
**时长**：约 35–45 分钟（4 篇，每篇 8–12 分钟）
**主轴**：Agent 一旦「读外部内容 + 调工具」，注入就是真实风险；核心是「把数据当数据，把指令当指令」

## 学完你能做到

1. 分清直接注入与间接注入，理解为什么间接注入是 Agent 特有风险。
2. 用「数据与指令隔离」思路做基本防御。
3. 落地一份注入防御清单（隔离标记 / 工具白名单 / 敏感操作确认）。
4. 知道防御的边界在哪——哪些能靠工程解决，哪些只能靠「最小权限」兜底。

## 阅读建议

- 第一次读：按顺序。C8-2 与 C7-4 的「外部内容隔离」直接衔接。
- 复习：只看 C8-4。
- 有环境：拿一段「网页里藏了指令」的文本喂给模型，看看它会不会照做——亲眼看一次比读十遍更警醒。
