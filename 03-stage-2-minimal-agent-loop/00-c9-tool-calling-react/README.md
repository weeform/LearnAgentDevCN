# C9 · 工具调用协议与 ReAct 手写
**面向**：已经会调 API、写 prompt，准备第一次手写 Agent 循环的人
**时长**：约 50–65 分钟（5 篇，每篇 10–15 分钟）
**主轴**：不依赖任何框架，手写一个能跑的最小 ReAct 循环

## 学完你能做到

1. 说清工具调用协议里消息数组怎么拼、并行调用怎么解析、结果怎么回填。
2. 理解 ReAct 的 Thought / Action / Observation 三段式，以及「让模型先想」为什么有效。
3. 手写一个 100 行以内、含完整终止条件与错误处理的 ReAct 循环。
4. 为循环设计可靠的终止条件（finish_reason、最大步数、停止信号）。
