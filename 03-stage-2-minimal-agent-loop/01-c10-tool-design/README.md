# C10 · 工具设计：粒度、描述与参数校验
**面向**：跑通了循环，但发现模型「经常调错工具 / 传错参数」的人
**时长**：约 40–50 分钟（4 篇，每篇 10–15 分钟）
**主轴**：模型调用成功率，八成取决于工具设计，而非模型强弱

## 学完你能做到

1. 判断一个工具该做多少事（粒度），拆得太细或太粗各有代价。
2. 写出「动宾结构、无歧义」的工具命名，和「写给模型看的」描述。
3. 在 JSON Schema 之外再加参数校验防线。
4. 用一份清单自查自己的工具定义。
