# C10 · 工具设计：粒度、描述、参数校验与操作型工具
**面向**：跑通了循环，但发现模型「经常调错工具 / 传错参数」的人；以及需要操作没有 API 的界面的人
**时长**：约 55–65 分钟（5 篇，每篇 10–15 分钟）
**主轴**：模型调用成功率，八成取决于工具设计，而非模型强弱；而「操作界面」类工具的设计规则与函数型工具完全不同

## 学完你能做到

1. 判断一个工具该做多少事（粒度），拆得太细或太粗各有代价。
2. 写出「动宾结构、无歧义」的工具命名，和「写给模型看的」描述。
3. 在 JSON Schema 之外再加参数校验防线。
4. 用一份清单自查自己的工具定义。
5. 判断什么时候该上 computer use / 浏览器自动化，以及它的五条设计要点与四条安全底线。
