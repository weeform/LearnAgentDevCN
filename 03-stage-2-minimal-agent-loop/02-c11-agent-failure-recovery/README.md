# C11 · Agent 失效模式与恢复
**面向**：循环跑通了，但发现它「会卡死、会乱来、会在该停的时候不停」的人
**时长**：约 45–60 分钟（5 篇，每篇 10–15 分钟）
**主轴**：让 Agent 从「能跑」到「活得下来」；以及判断一个任务到底该不该用 Agent

## 学完你能做到

1. 识别 Agent 的主要失效模式（报错、超时、死循环、幻觉调用）。
2. 掌握「错误回传给模型 → 自我修正」的完整套路。
3. 设计最大步数、死循环检测、超时处理。
4. 判断一个任务该不该用 Agent——这是最省钱的一项能力。
