# C12 · 工具生态：MCP 与能力复用

**面向**：已经会自己写 function calling 工具，想知道「能不能不重复造轮子」的人  
**时长**：约 40–50 分钟（4 篇，每篇 10–13 分钟）  
**主轴**：工具不该每次都从零写——MCP 让「接入」和「复用」变成标准化动作

## 学完你能做到

1. 说清 MCP 解决什么问题（N×M 集成），以及它的 client-server 架构与两种传输方式。
2. 把现成的 MCP server 接进自己的 Agent，把它的工具转成 function calling 工具。
3. 把自己的工具打包成 MCP server，让所有主流 Agent 客户端都能复用。
4. 识别 MCP 的特有安全风险（投毒、间接注入、过度授权、仿冒 server），并做基本防护。
