# 阶段 2 · Agent 最小闭环
**层级**：阶段（阶段 2 共 4 门课）
**规模**：4 门课 / 20 篇正文（另含 4 篇课程索引）
**时长**：约 4–5.5 小时（含动手时间）
**前置**：阶段 0、阶段 1
**产出**：手写一个 100 行以内的 ReAct 循环，跑通 3 个工具，并接入/打包一个 MCP server

## 这个阶段解决什么问题

前两个阶段都在准备，这里第一次真正让模型**自己决定下一步**。剥掉所有框架，Agent 的本质就一个循环：

```
模型输出 → 解析意图 → 执行工具 → 把结果喂回去 → 再问模型 → …… → 停
```

LangGraph、AutoGen、各家 SDK，拆开都是这个循环加一堆周边。所以这一阶段**手写一遍，不依赖任何框架**——先知道轮子长什么样，后面才判断得出该用哪个框架。

第二个重点是「工具」。模型能不能正确调用工具，八成取决于你的工具描述写得怎么样，而不是模型有多强。

## 学完你能做到

1. 手写完整的 ReAct 循环（Thought / Action / Observation），100 行以内，能跑。
2. 设计出调用成功率高的工具：粒度合适、命名准确、描述清楚、参数可校验。
3. 处理各种失败：工具报错怎么回传给模型、最大步数怎么定、死循环怎么检测。
4. 判断一个任务**该不该**用 Agent——这是最省钱的一项能力。
5. 把现成 MCP server 接进 Agent，或把自己的工具包成 MCP server 供复用。

## 推荐阅读顺序

1. **C9**— 先手写跑通循环，这是本阶段的骨架和交付物。
2. **C10**— 有了循环再打磨工具，因为工具质量直接决定调用成功率。
3. **C11**— 让循环「活下来」的工程手段，以及「该不该用 Agent」的判断。
4. **C12**— 工具生态的收尾：从「自己写工具」跳到「复用和分发工具」，接入或打包一个 MCP server。

## 阶段出口标准

1. **一个能跑的 ReAct 循环**：100 行以内，含完整终止条件与错误处理。
2. **3 个工具**：覆盖「查询类」「写入类」「计算类」各一，每个都有参数校验。
3. **trace 记录**：能回看一次任务的完整步骤——不必等阶段 5 的 C19，本阶段先按下面「trace 的最小做法」打 6 个字段就够用。
4. **一次失败复盘**：故意让工具报错，看模型能不能自我修正，记录结果。
5. **一个 MCP server**：接入一个现成 server，或把自己写的工具打包成 server。

### trace 的最小做法（本阶段就要有）

阶段 5 的 [C19-2](../06-stage-5-production-engineering/00-c19-observability/02-trace-span-structure.md) 给了 9 个字段，那是生产级口径。本阶段**只打 6 个**，一个 `list[dict]` 就够，不用上 OpenTelemetry：

| 字段 | 记什么 | 为什么现在就要 |
|---|---|---|
| `step` | 第几步（1、2、3…） | 没有步号，「第几步判断错了」说不出来 |
| `name` | `llm.call` / `tool.call` / `final` | 分不清这一步是模型在想还是工具在跑 |
| `input` / `output` | 截断到前 200 字 | 只能看到「它说了什么」，看不到「它看到了什么」 |
| `tokens` | 输入/输出分开记 | 「这任务花了多少」的唯一来源（后续 C21 要算账） |
| `elapsed_ms` | 每步耗时 | 超时和卡死全靠它定位 |
| `status` + `error` | `ok` / `error` / `retry` / `timeout`，失败时带错误码 | 数不出失败率的 trace 只能给人看，不能给程序用 |

剩下 3 个字段（`parent_id`、`model`、精确起止时间）等两件事出现时再补：**一个任务里有子 Agent**（阶段 3 的 C15-4、阶段 4）、**同一任务里换模型**（阶段 5 的 C22）。到那时再读 C19-2 全文。

## 与其他阶段的关系

- **依赖**：阶段 0（C1-4 工具调用参数、C5 稳定性）、阶段 1（system prompt 写法）
- **被依赖**：阶段 3、4 都建立在这个循环之上
- **强烈建议**：把阶段 5 的可观测性（C19-1 / C19-2）提前到本阶段一起做，做法就是上面那 6 个字段。没有 trace 的 Agent 循环 debug 起来是噩梦，等阶段 5 再补就晚了——但那不等于要从阶段 5 搬 5 篇过来读。
