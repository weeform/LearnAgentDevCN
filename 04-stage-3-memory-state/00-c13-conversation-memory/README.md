# C13 · 会话记忆与压缩
**面向**：已经能跑 Agent 循环，但任务一长上下文就爆、成本翻倍的人
**时长**：约 45–60 分钟（5 篇，每篇 8–15 分钟）
**主轴**：短期记忆就是消息数组，学会怎么管、怎么压、怎么量代价

## 学完你能做到

1. 说清「短期记忆」的本质就是消息数组，以及 system / user / assistant / tool 四种角色各自怎么处理。
2. 判断什么该摘要、什么该删、什么必须原样保留，并给出依据。
3. 处理工具返回这个「预算黑洞」：截断、摘要、落盘+引用、分页。
4. 用量化指标（成功率、成本）衡量压缩策略，而不是凭感觉。
