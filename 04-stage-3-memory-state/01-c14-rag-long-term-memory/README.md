# C14 · 检索与长期记忆（RAG 全链路）
**面向**：要给 Agent 装上「长期记忆」的人——不想每轮把全部资料塞进上下文
**时长**：约 50–65 分钟（5 篇，每篇 10–15 分钟）
**主轴**：先判断该不该上 RAG，再走通切分 → Embedding → 检索 → 重排 → 维护全链路

## 学完你能做到

1. 用具体判据说清「什么时候根本不需要 RAG」，而不是默认上向量库。
2. 选切分策略（按段落 / 语义 / 结构）与合适的 Embedding 模型。
3. 搭混合检索（向量 + 关键词），并判断向量库选本地还是云服务。
4. 解释 rerank 为什么几乎总值得，并处理长期记忆的更新、去重、过期与矛盾。
