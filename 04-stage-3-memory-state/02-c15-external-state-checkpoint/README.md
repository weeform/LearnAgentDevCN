# C15 · 外部状态与断点续跑
**面向**：跑过长任务、被「进程一挂进度全丢」坑过的人
**时长**：约 45–60 分钟（5 篇，每篇 8–15 分钟）
**主轴**：把「状态」从上下文里搬出来，让任务可恢复、可干预、可审计

## 学完你能做到

1. 把任务进度写成显式状态机，而不是隐含在消息数组里。
2. 实现断点续跑：进程 kill 掉再起，能从上次状态继续。
3. 用「按需加载」代替「全塞进去」，用上下文分区稳住缓存命中。
4. 用子 Agent 隔离脏上下文，只回传结论。
