# C16 · 拆分信号与编排模式
**面向**：觉得「单 Agent 不够用」，想拆成多 Agent、又拿不准该不该拆的人
**时长**：约 45–60 分钟（5 篇，每篇 8–15 分钟）
**主轴**：先判断该不该拆，再学四种编排拓扑

## 学完你能做到

1. 用三个具体信号判断一个任务该不该拆成多 Agent。
2. 算清拆分的四项成本（token、延迟、调试、一致性）。
3. 说清四种编排模式的拓扑、适用场景与失败传播方式。
4. 识别「多数真实系统是四种模式的组合」。
