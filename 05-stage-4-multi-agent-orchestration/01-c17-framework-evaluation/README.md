# C17 · 框架横评与自研取舍
**面向**：在 LangGraph / AutoGen / CrewAI 之间纠结、或纠结要不要自研的人
**时长**：约 40–50 分钟（4 篇，每篇 10–15 分钟）
**主轴**：不比谁更火，比三个维度——状态管理模型、可观测性支持、逃生舱

## 学完你能做到

1. 用三个维度评判任何 Agent 框架，而不是看名气。
2. 对 LangGraph / AutoGen / CrewAI 的定位与取舍有自己的判断。
3. 知道什么是「逃生舱」，以及什么时候自研更划算。
4. 理解「框架半年一变」的时效风险，把框架结论当「维度」而非「答案」。
