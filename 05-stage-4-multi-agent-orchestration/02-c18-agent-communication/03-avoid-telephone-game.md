# C18-3 · 避免「传话游戏」
> 阅读约 10 分钟。目标：识别并防止信息在多个 Agent 间层层传递时的损耗。

## 1. 什么是「传话游戏」

你玩过「传话游戏」吗？一句话经过 10 个人口耳相传，最后面目全非。多 Agent 系统里，**同样的损耗每时每刻都在发生**：

```
Agent A 的原始结论 → 摘要传给 B → B 再转述给 C → C 再综合给 D → 用户看到的
     100% 信息          90%           75%          60%             …?
```

每一层传递，信息都被**摘要、误读、选择性转述**损耗一点，最终结论可能和原始事实差了十万八千里。

## 2. 损耗的三个来源

| 来源 | 表现 |
|---|---|
| **摘要失真** | 上游压掉了「当时觉得不重要、其实很关键」的细节 |
| **误读** | 下游把上游的话理解偏了，再按自己的理解转述 |
| **选择性转述** | 下游只转述「符合自己判断」的部分，丢掉相反证据 |

其中**选择性转述**最隐蔽也最危险——它不是「信息丢了」，而是「信息被有偏见地筛过了」。

## 3. 四条防线

1. **传结构化数据，不传转述**。让下游拿到的是「字段」而不是「上游的重新表述」。结构化消息天然抗损耗（见 C18-1）。

2. **传原始引用，不传摘要**。关键事实附上「原始出处/原始数据」，而不是只给一句摘要。下游要看细节，能直接追溯到源头（呼应 C13-3 的落盘+引用）。

3. **减少传递层级**。每多一层传递就多一份损耗。能「扇出后直接汇总」的，就别「层层中转」。

4. **关键信息显式标注**。让上游在传递时把「哪些是关键结论、哪些是依据、哪些是不确定的」分开标注，下游就不会把「不确定的推测」当成「确定的事实」往下传。

## 4. 一句话原则

> **传事实，不传转述；传引用，不传摘要；减少层级，标注确定性。**

## 5. 小结

- 传话游戏：信息在多 Agent 间层层传递时被摘要、误读、选择性转述损耗。
- 损耗三来源：摘要失真、误读、选择性转述（最隐蔽）。
- 四防线：结构化数据、原始引用、减少层级、标注确定性。
