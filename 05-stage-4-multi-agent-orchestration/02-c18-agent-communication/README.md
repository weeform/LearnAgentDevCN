# C18 · Agent 间通信与结果聚合
**面向**：搭多 Agent 系统时，被「Agent 之间怎么传话、怎么合并结果」卡住的人
**时长**：约 40–50 分钟（4 篇，每篇 10–15 分钟）
**主轴**：结构化消息代替长文本，扇出后科学聚合，别让信息在传递中损耗

## 学完你能做到

1. 判断 Agent 间该用结构化消息还是自然语言，各适合什么场景。
2. 实现扇出后的聚合：投票、打分、去重合并。
3. 识别并避免「传话游戏」式的信息损耗。
4. 设计一套不互相甩锅、可校验的通信协议。
