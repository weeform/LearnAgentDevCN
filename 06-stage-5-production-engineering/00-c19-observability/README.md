# C19 · 可观测性：trace 与日志规范
**面向**：已经能跑通 Agent，但一旦跑偏只能「干瞪眼」的人
**时长**：约 50–65 分钟（5 篇，每篇 10–15 分钟）
**主轴**：先讲清为什么必须可观测，再设计 trace 结构，最后落地

## 学完你能做到

1. 说清为什么 Agent 的可观测性是「第一优先级」而不是「上线前补丁」。
2. 设计一次 Agent 运行该记录哪些字段（输入、输出、token、耗时、工具参数、模型名）。
3. 制定结构化日志规范与采样策略，并处理敏感信息脱敏。
4. 在「自建最小 trace」和「现成工具（OpenTelemetry / LangSmith 类）」之间做取舍。
