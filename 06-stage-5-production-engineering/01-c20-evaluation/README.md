# C20 · 评测：评测集、LLM-as-judge、回归
**面向**：已经能跑通 Agent 并有了 trace，但「改完不知道变好还是变坏」的人
**时长**：约 80–100 分钟（6 篇，每篇 12–16 分钟）
**主轴**：先造尺子（评测集），再设计裁判（judge），把评测接进 CI 变成门禁，最后补上「上线之后」这一段——离线门禁挡不住新出现的坑

## 学完你能做到

1. 从线上 trace 造出一个覆盖真实分布的评测集（含黄金集与失败路径）。
2. 设计一个 rubric 清晰、输出可解析的 LLM-as-judge，并选对打分尺度。
3. 识别 judge 的四种已知偏差，并用可落地手段缓解。
4. 把评测接进 CI：改 prompt/模型后一键跑对比，用回归通过线做门禁。
5. 用 trace 直接算出三个在线指标，并把线上失败样本筛成回归用例（含评测集的新陈代谢规则）。

## 阅读建议

- 第一次读：按顺序，C20-2 是本课核心——rubric 和尺度定对了，judge 才可信；C20-5 决定这套东西能不能长期活下去。
- 复习：只看 C20-6。
- 有环境：从 C19 攒下的 trace 里抽 30 条真实样本，写一个最小 judge 跑一次二元打分，再手动抽查 10 条算一致率。
