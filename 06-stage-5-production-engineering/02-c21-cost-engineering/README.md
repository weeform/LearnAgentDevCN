# C21 · 成本工程：预算、分级与告警
**面向**：Agent 已经能跑通，但「每跑一次花多少钱」心里没数、也管不住的人
**时长**：约 45–55 分钟（4 篇，每篇 10–15 分钟）
**主轴**：先算清一次任务多少钱，再装上预算告警，最后用缓存和模型分级把成本打下来

## 学完你能做到

1. 把「一次任务」的成本算清楚：输入 + 输出 + 工具返回回填 + 重试，一个都不漏。
2. 按任务/用户/天三层设预算上限，并设计「逼近告警 + 超限熔断」的两级控制。
3. 监控缓存命中率，用「稳定前缀」提升它，并在命中率暴跌时第一时间发现。
4. 建立模型分级：贵模型做难活、便宜模型做简单活，按「任务难度 + 错误代价」定阈值。

## 阅读建议

- 第一次读：按顺序，C21-1 是地基——账算不清，后面预算和分级都是空谈。
- 复习：只看 C21-4 的速查表。
- 有环境：拿 C19 埋点攒下的一次真实任务 trace，套 C21-1 的脚本算一次账，再给这次任务设一条预算。
