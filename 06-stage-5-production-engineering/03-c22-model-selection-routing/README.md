# C22 · 模型选型与路由
**面向**：已经能算出单个任务成本、但面对一堆模型不知道「哪个活派给哪个」的人
**时长**：约 40–50 分钟（4 篇，每篇 10–13 分钟）
**主轴**：先建立选型的四个维度，再看维度之间怎么打架，最后落到分级路由与长上下文/开源的临界点

## 学完你能做到

1. 用四个维度（能力、价格、延迟、上下文）量化地比较模型，而不是看榜单拍脑袋。
2. 说清四个维度之间的取舍关系，用权衡矩阵做「够用即止」的选型决策。
3. 设计一条分级路由规则：便宜模型干简单活、贵模型干难活，带失败升级与成本控制。
4. 在「长上下文」和「RAG」之间做对选择，并算清开源自建的临界点。

## 阅读建议

- 第一次读：按顺序，C22-3 是本课核心——前面两个维度的分析都服务于「把它落成一条路由规则」。
- 复习：只看 C22-4 后半的速查表。
- 有环境：给阶段 2 的 ReAct 循环加一个「便宜模型先上、失败升级」的分级路由，跑一组真实任务对比总成本。
