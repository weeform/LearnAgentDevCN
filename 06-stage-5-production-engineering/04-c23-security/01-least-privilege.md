# C23-1 · 最小权限与工具权限分级
> 阅读约 12 分钟。目标：学会给每个工具定权限级别，把「最小权限」从一句口号落成可执行的工具定义。

## 1. 一句话结论

> Agent 不是「信任它」，而是「限制它」。它拿到什么权限，出事时就能造成多大损失。

最小权限原则：Agent 只拿到完成当前任务所需的**最小**权限，多一分都不给。听起来是常识，但多数人做的是「把能用到的工具全塞给它，出了事再收」——这就把「出事」当成了唯一的学习成本。

## 2. 权限四级

给权限分级的价值在于：**风险不是连续的，而是分层的**。「查一下」和「删掉」不该享受同等的默认信任。

| 级别 | 含义 | 典型工具 |
|---|---|---|
| `read` 只读 | 只能查，不能改 | 查天气、查库、读文件 |
| `write` 写 | 能新增 / 修改 | 存笔记、写文件、发 HTTP 请求 |
| `spend` 花钱 | 会扣钱 / 消耗资源 | 调付费 API、下单、发短信 |
| `destroy` 破坏 | 不可逆 / 高影响 | 删库、删文件、关服务 |

> 经验值：绝大多数任务只需要「只读 + 写」两级。**「花钱」和「破坏」要单独拎出来**，默认配人工确认（见 C23-3），不放进「写」里混为一谈。

## 3. 职责互斥：「读数据的」和「能花钱的」不该是同一个 Agent

这条直接呼应 C16-1 的「职责互斥」拆分信号。单一 Agent 如果既读数据又能下单，prompt 注入一旦成功，攻击者就能让它「查完价直接下单」——因为「查价」和「下单」在同一个上下文里，中间没有任何闸门。

> 结论：把「读」和「花钱」拆成两个 Agent。读 Agent 的输出只是一堆数据，花钱 Agent 收到的是「已通过确认的指令」，中间隔着人工确认这道闸。拆开的成本是 token 和延迟，换来的是「注入最多只能污染读，摸不到钱」。

## 4. 权限清单怎么落到工具定义里

权限不能靠「开发者心里有数」，要落成三样东西：

1. **工具定义里写死级别**——在 description 里标注，让模型也「知道」自己不能乱来。
2. **一张权限表**——`name → level → 是否需要确认`，这是审计和检查的唯一真相源。
3. **执行器里强制校验**——跨级调用直接拒绝，不靠 prompt 自觉。

```python
PERMISSIONS = {
    "search_weather": {"level": "read",    "confirm": False},
    "save_note":     {"level": "write",   "confirm": False},
    "send_sms":      {"level": "spend",   "confirm": True},
    "drop_table":    {"level": "destroy", "confirm": True},
}

def execute(name: str, args: dict):
    p = PERMISSIONS.get(name)
    if p is None:
        raise PermissionError(f"未注册工具: {name}")
    if p["confirm"] and not confirmed(name, args):
        raise PermissionError(f"{name} 需人工确认，已拦截")
    return funcs[name](**args)
```

> 关键点：校验在 `execute()` 这一层做，**不管模型怎么调、参数怎么变，都绕不过去**。prompt 里写「请不要删库」是无力的，代码里 `raise` 才有用。

## 5. 最小权限的三个落点

「最小权限」不只管「给哪些工具」，还有两个更容易被忽略的面：

1. **工具面最小化**：用不到的工具就不给。每多一个工具，就多一个注入和误用的入口。
2. **数据面最小化**：工具只返回任务需要的那几列，而不是整张表（这是 C23-4 防外泄的主场）。
3. **作用域最小化**：读库用只读账号，写文件限死目录，不让它摸到全盘。

> 一句话：权限清单 = 给谁什么工具 + 每个工具能碰什么数据 + 每个工具能在哪个范围操作。三处一起收，才算最小。

## 6. 小结

- 权限四级：只读 / 写 / 花钱 / 破坏，越靠后越要收紧。
- 职责互斥：读数据和能花钱的拆成两个 Agent，中间隔确认（C16-1）。
- 权限清单落到「工具定义 + 权限表 + 执行器强制校验」，不靠口头约定。
- 最小权限 = 工具面 + 数据面 + 作用域，三处一起收。
