# C23 · 安全：权限、沙箱与人工确认
**面向**：已经能跑通 Agent，但还没想清楚「它能碰什么、不能碰什么」的人
**时长**：约 50–65 分钟（5 篇，每篇 10–15 分钟）
**主轴**：先划权限边界，再管执行环境，最后补人工兜底与系统稳定性

## 学完你能做到

1. 给每个工具定权限级别（只读 / 写 / 花钱 / 破坏），把「最小权限」落成可执行的工具定义。
2. 说清代码执行为什么必须沙箱，选一种沙箱实现并做 CPU/内存/网络/超时限制。
3. 设计人工确认的介入点与粒度，避免「问太多形同虚设」。
4. 处理长时任务的超时、幂等、部分失败补偿，并做数据外泄防护。
5. 产出一份「权限清单 + 确认点清单」，作为阶段 6 项目的安全基线。

## 阅读建议

- 第一次读：按顺序，C23-1 是地基——权限分级错了，后面沙箱和确认都无从谈起。
- 复习：只看 C23-5。
- 有环境：翻出阶段 2 的 ReAct 代码，给每个工具标权限级别，把 `calculate` 从 `eval` 换成沙箱执行。
