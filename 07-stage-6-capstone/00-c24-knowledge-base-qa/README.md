# C24 · 项目一：知识库问答 Agent（RAG + 引用）
**面向**：已学完阶段 3、想交付第一个完整 Agent 项目的人
**时长**：约 8–12 小时（动手为主，阅读约 1 小时）
**难点**：切分破坏语义完整性；模型倾向编造引用

## 学完你能做到

1. 交付一个能跑的知识库问答 Agent 仓库，README 说清怎么跑、依赖什么、有什么限制。
2. 用 50 条评测集给出可溯源率（≥95%）与拒答准确率的量化结果，而不是「感觉还行」。
3. 说清单次问答的成本结构，并给出至少一项优化前后的对比数据。
4. 在作品集里讲清三个关键取舍，以及「如果重做会改哪里」。
