# C25 · 项目二：数据分析 Agent（代码执行 + 沙箱）
**面向**：已经学完阶段 2~4、想把「让模型写代码并安全执行」落成一个完整项目的人
**时长**：约 6–8 小时（动手为主，阅读约 1 小时）
**难点**：模型算错但说得很有信心——必须靠独立的数值校验环节拦住；同时保证代码执行零逃逸

## 学完你能做到

1. 定义并量化「正确结论」：数值正确（黄金答案复算）+ 结论合理，两层验收标准。
2. 设计并实现「自然语言 → 生成代码/SQL → 沙箱执行 → 回传修正 → 独立校验 → 结论」的完整流水线。
3. 用 Docker 沙箱 + ast 白名单实现零逃逸的代码执行，并留下可复现的验证记录。
4. 交付一份带评测集、正确率、成本数据和 3 个失败案例的完整项目，可直接放进作品集。

## 阅读建议

- 第一次做：按顺序，边读边敲。C25-3 是本课核心——代码跑通了，C25-4 才有数据可测。
- 复习：只读 C25-5 的三个取舍 + C25-1 的验收标准。
- 有环境：先把 C25-3 的 SQL 侧跑通，再上 Docker 沙箱；评测集（C25-4）务必在写代码前定下来。
