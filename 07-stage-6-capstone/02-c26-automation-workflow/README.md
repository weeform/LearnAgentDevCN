# C26 · 项目三：自动化工作流 Agent（多步 + 长时任务）
**面向**：已经能跑通 ReAct / 多 Agent，但任务一跑长（几十分钟到几小时）就抓瞎的人
**时长**：动手为主，约 6–10 小时（阅读 5 篇约 1 小时）
**难点**：长时任务的状态管理，以及「做到一半发现方向错了」的回滚

## 学完你能做到

1. 把一次「多步 + 跨小时 + 中途要人确认」的任务，拆成显式状态机并落盘。
2. 让进程被 kill 后能从 checkpoint 续跑，已完成的批次不重做。
3. 给任务加两道保险：成本上限熔断（超预算自动停）、敏感步骤人工确认（不点头不执行）。
4. 说清幂等与补偿怎么设计、方向错了怎么回滚，并把这三项写成可复现的验收测试。

- 第一次读：按顺序。C26-2 是本课核心——状态机与 checkpoint 设计对了，续跑和回滚才做得动。
