# 阶段 6 · 实战项目
**层级**：阶段（阶段 6 共 3 个项目）
**规模**：3 门课 / 15 篇正文（另含 3 篇课程索引）
**时长**：约 20–30 小时（动手为主，阅读约 2 小时）
**前置**：6.1 需阶段 3；6.2 需阶段 4 + 阶段 5 的安全（C23）；6.3 需阶段 4 + 阶段 5
**产出**：3 个能放进作品集的项目

## 这个阶段解决什么问题

前面五个阶段学的都是零件。这一阶段把它们焊成完整的东西——而且必须完整到能拿给别人看：**有 README、有评测结果、有成本数据**。

三个项目是刻意选的，各自压一个不同的难点：

| 项目 | 主要难点 | 对应能力 |
|---|---|---|
| 6.1 知识库问答 | 检索质量决定一切 | 阶段 3 的 RAG 全链路 |
| 6.2 数据分析 | 让模型写代码并安全执行 | 沙箱、代码执行、结果验证 |
| 6.3 自动化工作流 | 长时任务的状态与恢复 | 状态机、断点续跑、人工介入 |

> **性质提醒**：这三门课是「照着做」的 lab，不是「通勤读」的文章——建议在电脑前读、边读边敲，不适合地铁上刷。

## 学完你能做到

1. 独立交付一个完整的 Agent 应用，从需求到上线。
2. 为它写评测集并给出量化结果，而不是「我觉得效果还行」。
3. 说清它的成本结构：单次任务多少钱、怎么优化的。
4. 在作品集里讲明白设计取舍（为什么这么拆、为什么选这个模型、哪里做了妥协）。

## 推荐阅读顺序

1. **C24**— 先做 RAG 问答，它只依赖阶段 3，学完阶段 3 就能开工，不用等全部学完。
2. **C25**— 数据分析项目，把 C23 的沙箱与代码执行落到实战。
3. **C26**— 自动化工作流压轴，综合阶段 4 的编排 + 阶段 5 的全部工程化能力。

## 阶段出口标准

每个项目交付四样东西，缺一不算完成：

1. **可运行的仓库**：README 写清楚怎么跑、依赖什么、有什么限制。
2. **评测结果**：评测集 + 跑分 + 至少 3 个失败案例的分析。
3. **成本数据**：单次任务平均成本、优化前后的对比。
4. **设计复盘**：至少 3 个关键取舍，以及「如果重做会改哪里」。
